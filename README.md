# BS Statistics | PUP



Welcome to the official digital space of the BS Statistics program at the Polytechnic University of the Philippines (PUP). This repository hosts a responsive platform designed to showcase our rigorous curriculum, student life, and academic research.

## 🌟 Key Features
* **Dynamic Theming:** Built-in light and dark mode toggle.
* **Interactive Research Directory:** Searchable database of batch research papers and methodologies.
* **Program Information:** Details on career pathways, faculty, and the Statistics Students Clique (SSC).
* **Student Hub:** Direct contact details for sections BSSTAT 4-1 (Iskatistics) and BSSTAT 4-2 (Blk Two-tailed).

## 🤝 Contributing
To contribute, please reach out to the respective section emails or fork this repository and submit a pull request.
